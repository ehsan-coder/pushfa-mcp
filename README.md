# MCP پوشفا

MCP رسمی پوشفا برای خواندن راهنمای نصب وب، اندروید و iOS و کار با وب‌سرویس‌های یک سرویس پوشفا. روی سیستم شما با `stdio` اجرا می‌شود و برای دریافت راهنما و عملیات سرویس به `pushfa.com` متصل می‌شود.

[صفحهٔ نصب و دانلود](https://pushfa.com/mcp) · [مستندات فنی MCP](https://pushfa.com/index/doc/mcp)

## نصب

به Node.js نسخهٔ ۲۲ یا بالاتر و کلاینتی با پشتیبانی از MCP محلی نیاز دارید. برای نصب از همین مخزن، این تنظیم را در کلاینت‌های دارای قالب `mcpServers` وارد کنید.

```json
{
  "mcpServers": {
    "pushfa": {
      "command": "npx",
      "args": ["--yes", "--package=git+https://github.com/ehsan-coder/pushfa-mcp.git", "pushfa-mcp"]
    }
  }
}
```

برای نصب دستی، [فایل یکپارچه](https://pushfa.com/downloads/pushfa-mcp.mjs) را بگیرید و در تنظیمات کلاینت، فرمان `node` و مسیر کامل فایل را وارد کنید. اگر مخزن را کلون یا ZIP آن را استخراج کرده‌اید، `node src/index.mjs` نیز از ریشهٔ پروژه اجرا می‌شود. اجرای کد به نصب وابستگی نیاز ندارد.

## کلیدها و دسترسی‌ها

برای خواندن راهنماها هیچ کلیدی لازم نیست. برای کار با سرویس، متغیرها را در بخش `env` تنظیمات محلی اتصال وارد کنید و اتصال را دوباره راه‌اندازی کنید.

| متغیر | کاربرد |
| --- | --- |
| `PUSHFA_API_PUBLIC_KEY` | کلید عمومی سرویس |
| `PUSHFA_API_PRIVATE_KEY` | کلید خصوصی همان سرویس |
| `PUSHFA_MCP_ENABLE_SEND` | مقدار رشته‌ای `true` برای فعال‌کردن ارسال |
| `PUSHFA_MCP_ENABLE_MANAGEMENT` | مقدار رشته‌ای `true` برای عملیات مدیریتی |
| `PUSHFA_MCP_ENABLE_IDENTITY` | مقدار رشته‌ای `true` برای پوش‌باکس و Auth Push |

با هر دو کلید، ابزارهای استعلامِ وضعیت اعلان و اشتراک، Alias، براکت‌ها و اطلاعات تاپیک فعال می‌شوند. ابزارهای ارسال به شناسهٔ مخاطب، توکن FCM، Alias، Custom Alias و تاپیک، بسته به نوع اعلان و وب‌سرویس درخواستی، دسترسی ارسال را می‌خواهند. ابزارهای مدیریتی شامل تغییر Alias و براکت، عضویت تاپیک، کاربر آزمایشی و ثبت پروفایل و رویداد RetenX هستند.

دستیار ابتدا یک پیش‌نمایش با `pushfa_prepare_*` می‌گیرد. پس از تأیید شما، `pushfa_send_notification` ارسال را ثبت می‌کند و `pushfa_confirm_operation` پیش‌نمایش مدیریت یا هویت را اجرا می‌کند. شناسهٔ پیش‌نمایش پنج دقیقه در همان پردازش معتبر است و فقط یک بار می‌توان برای اجرای عملیات از آن استفاده کرد. کلید خصوصی را در تنظیمات محلی نگه دارید. امکانات سرویس و هزینه‌ها طبق پلن و تعرفهٔ پوشفا محاسبه می‌شوند.

## نمونه درخواست

- «راهنمای Web Push پوشفا را بخوان و مراحل لازم برای نصب در این پروژه را انجام بده.»
- «وضعیت اعلان با شناسهٔ [شناسه] را بررسی کن و زمان تحویل یا کد خطا را بگو.»
- «برای کاربر با Alias [شناسه] اعلان آماده کن و پیش از ارسال پیش‌نمایش را نشان بده.»

## ساختار کد

| مسیر | مسئولیت |
| --- | --- |
| `src/index.mjs` | ورودی برنامه و پروتکل MCP روی stdin و stdout |
| `src/tools.mjs` و `src/schemas.mjs` | تعریف ابزارها و اعتبارسنجی ورودی |
| `src/client.mjs` و `src/config.mjs` | اتصال به API پوشفا و تنظیم دسترسی ابزارها |
| `src/guides.mjs` و `src/drafts.mjs` | خواندن راهنماها و مدیریت پیش‌نمایش‌های یک‌بارمصرف |
| `pushfa-mcp.mjs` | خروجی یکپارچه برای دانلود و اجرای مستقیم |

بعد از تغییر کد در `src/`، با `npm ci` و سپس `npm run build` فایل یکپارچه را دوباره تولید کنید.
